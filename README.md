# 사자가온다 | Website

사자가온다 공식 홈페이지 리뉴얼 작업용 저장소입니다.

- 기존 운영 사이트: https://sjgod.kr/
- GitHub Pages 개발 미리보기(활성화 시): https://jyhome1228-cyber.github.io/sjgod/
- 상태: 초기 개발 구조 구성 / 운영 도메인 연결 전

## 로컬 확인
별도 빌드 없이 `index.html`을 브라우저로 열거나 로컬 정적 서버로 확인할 수 있습니다.

## 구조
- `index.html`: 메인 페이지 기본 마크업
- `assets/css/style.css`: 공통 스타일 및 반응형
- `assets/js/main.js`: 메뉴, 스크롤 UI
- `docs/CONTENT_CHECKLIST.md`: 실제 운영 정보 확인 및 향후 수정 항목

## 배포 관련 주의
현 운영 사이트(sjgod.kr)의 DNS나 도메인 연결은 변경하지 않았습니다.
GitHub Pages는 저장소 Settings > Pages에서 `main / (root)`를 선택해 별도 테스트할 수 있습니다.
운영 사이트로 전환하기 전에 원본 이미지·문구·법적 표기 및 문의 채널을 검수해야 합니다.
