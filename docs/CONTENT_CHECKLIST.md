# 사자가온다 홈페이지 콘텐츠 점검표

> 본 저장소의 첫 버전은 **디자인/구조 확인용 시안**입니다. 사실 확인이 필요한 기업 정보는 임의로 작성하지 않습니다.

## 검수 전 확인할 내용
- [ ] 공식 국문/영문 회사명 및 로고 원본
- [ ] 회사 소개, 핵심 메시지, 사업 소개 문구
- [ ] 기존 서비스(Q샵, 501g, 퀘스트스쿨 등)의 운영 여부와 공식 링크
- [ ] C-Finder 소개 범위와 공개 가능한 정보, 공식 사용 승인
- [ ] 프로젝트/실적/언론 보도 링크
- [ ] 공식 사업자명, 대표자, 사업자등록정보, 사업장 주소
- [ ] 문의 이메일 또는 공식 문의 폼 연동
- [ ] 개인정보처리방침 및 관련 고지
- [ ] 실제 이미지/영상/폰트의 사용 권한
- [ ] 국문/영문 페이지 제공 범위

## 수정 원칙
1. 운영 도메인 sjgod.kr은 최종 승인 전까지 유지한다.
2. 검증되지 않은 수치·성과·파트너 관계를 임의 표기하지 않는다.
3. 모바일 우선으로 화면을 검수한다.
4. 모든 버튼은 실제 동작하도록 구현한다. 미연결 버튼은 노출하지 않는다.
5. 사이트 링크와 메타 정보, 검색 최적화 요소를 오픈 전 점검한다.
