# 사자가온다 사이트 UI 디자인 기준

이 문서는 향후 GitHub 수정 시 항상 적용하는 디자인 원칙입니다.

## 톤
- 기존 브랜드의 블랙/화이트, 절제된 타이포그래피 중심
- 템플릿 같은 큰 흰색 카드 나열, 빈 공간 과다 사용 지양
- 장식용 영문 라벨이나 강조 배경 남용 지양
- 콘텐츠를 중심에 두고 정보 밀도, 정렬, 읽기 순서 우선

## 타이포그래피 (PC 최대값)
- 메인 이미지 히어로: 42px 이내
- 하위 페이지 상단 H1: 34px 이내
- 일반 섹션 H2: 30px 이내
- 카드 H3: 19px 이내
- 본문 14~15px, 캡션 12~13px
- 헤더 메뉴 13~14px, 영문 라벨 10~11px

## 공간과 정렬
- 공통 최대 폭 1440px
- 일반 섹션 상하 60~76px (모바일 46~52px)
- 카드 패딩 보통 18~24px
- 콘텐츠가 적으면 높이 고정 금지, 과도한 min-height 금지
- 모바일의 제목 줄바꿈과 버튼 너비를 별도 점검

## 예외
- 강한 인상 연출을 위한 메인 풀스크린 일러스트에는 별도 기준 적용
- 사용자가 특정 시안을 기준으로 지정하면 그 의도와 구성 우선

## 검수
- 메인/프로그램/솔루션/교구·교재/실적/대표 강연/회사소개/문의/뉴스 전체 페이지 동일한 위계 적용
- 새 섹션 추가 시 기존 대형 타이포·카드 스타일 복제하지 않음
