# 사자가온다 사이트 디자인 가이드 (2026-11-15)

## 색상 원칙 — 필수
- **모든 페이지·모든 섹션 배경은 검정(#000000)**으로 통일한다. 흰 배경의 교차 섹션을 만들지 않는다.
- 기본 텍스트는 흰색(#FFFFFF), 보조 텍스트 및 구분선은 무채색 회색만 사용한다.
- 회색은 본문 위계와 구분선에만 사용하는 무채색 보조톤이다.
- 네이비, 청록, 연두, 주황 등 유채색은 배경, 버튼, 강조 텍스트, 아이콘에 사용하지 않는다.
- 모든 하위 페이지, 헤더, 푸터, 폼, 반응형 상태, hover 상태에 동일 적용한다.
- 사용자가 제공한 콘텐츠 사진/제품 이미지의 실제 색은 임의로 훼손하지 않는다. 이미지의 흑백화는 별도 요청 시 수행한다.

## 전체 방향
- 나인웍스·애플 사이트처럼 **내용 중심의 단정한 위계**를 적용한다.
- 'SAJAGAONDA / LECTURE', 'SPEAKER', 'PERFORMANCE ARCHIVE' 같은 장식용 영문 라벨을 사용하지 않는다.
- 슬래시, 대문자 영어 캡션, 강조 배경 박스, 불필요한 장식 기호와 과도한 카드 레이아웃을 쓰지 않는다.
- 사진이나 결과물처럼 실질적인 시각 자료를 중심에 둔다.
- 타이포그래피를 과장하지 않고, 빈 공간을 과도하게 확보하지 않는다.

## 크기와 간격
- 최대 콘텐츠 폭 1440px
- 메인 이미지 히어로 제목 30~42px
- 하위 페이지 H1 27~34px, 섹션 H2 23~30px, 카드/리스트 H3 17~19px
- 본문 13~15px, 안내/메타 12~13px
- 서브페이지 헤더는 짧은 타이틀+설명만 사용
- 섹션 상하 여백 PC 64px 내외, 모바일 43~48px
- 카드 대신 경계선과 리스트를 우선 활용. 카드가 필요하면 기능/콘텐츠에 근거하여 사용한다.
- 메인과 하위 페이지 모두 블랙 배경으로 유지하며, 콘텐츠 이미지 자체의 색은 원본을 존중한다.
- 파비콘은 `favicon.svg` 사자 심볼을 사용하고, 신규 페이지에 `<link rel="icon" type="image/svg+xml" href="favicon.svg">`를 반드시 포함한다.

## 품질 검사
- 메인, 프로그램, 솔루션, 교구·교재, 실적, 대표 강연, 회사소개, 도입 문의, 뉴스 전 페이지 공통 규칙 적용
- 모바일에서 제목의 과도한 줄바꿈, 헤더 메뉴, 콘텐츠 밀도 확인
- 실제 운영 내용 외 '제공된 자료', '전략안 기준', '디자인 참고', '향후 추가' 같은 내부 작업 안내 문구는 고객 노출 최소화
- 배포 성공 여부는 GitHub Actions / Pages에서 별도 확인한다.

## 표현·가독성 (2026-11-15 확정)
- 제목 마지막에 장식용 온점(.)을 붙이지 않는다.
- 링크와 버튼에 ↗, ↘ 같은 대각선 화살표를 추가하지 않는다. 텍스트 자체가 클릭 대상임을 알 수 있게 만든다.
- 본문을 가로로 무한히 늘리지 않고, 읽기 좋은 최대 너비(약 620~660px)와 자연스러운 줄바꿈을 적용한다.
- 본문 크기는 PC 15~16px, 모바일 14~15px을 우선한다. 너무 작은 회색 글자는 피한다.
- 영문 장식 라벨, 불필요한 구분 기호, 과한 CTA 장식은 만들지 않는다.

## 연혁 및 실적 데이터 원칙
- 기존 사자가온다 홈페이지에 게시된 연혁을 연도별 개별 항목 그대로 보존한다. 요약 문구로 대체하지 않는다.
- 현재 `company.html`에는 2021~2023 기존 사이트 화면과 2024~2026 리뉴얼 전략안·언론 목록에서 확인된 주요 이력 49건을 표시한다.
- 연혁과 언론 보도는 성격이 다르므로 동일한 실적으로 중복 계산하지 않는다.
- 입력되지 않은 원본 연혁이나 제공되지 않은 인증 실적은 추정하여 추가하지 않는다.
- 디자인은 연도 + 실제 이력 텍스트의 단정한 세로 목록을 기준으로 하고 색상 점·장식선은 사용하지 않는다.
- 새 자료를 제공받으면 기존 데이터를 먼저 대조한 후 추가·수정한다.
